# Chat-App

WebSocket-based real-time chat application.

This repository contains a TypeScript chat app that demonstrates real-time messaging using WebSockets.

## Quick start

1. Clone the repo

   git clone https://github.com/n1njaO7/Chat-App.git
   cd Chat-App

2. Install dependencies

   npm install

3. Run the app

   npm run dev

4. Build

   npm run build


## What you'll find

- TypeScript source code for client and server
- CSS for styling
